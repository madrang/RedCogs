# Harness resources

The reference set of the AgentEliza harness, written for the agent.

- `harness-tools.md` — every harness tool with its parameters, caps, result formats, and error texts.
- `discord-markdown.md` — the full Discord markdown notation with examples.
- `status.md` — the live status of the harness: provider, model, vision, the context of this conversation, sessions, usage allowance, and limits. It is built at every read, so it always shows the current state.
